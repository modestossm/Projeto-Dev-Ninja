> Projeto final do curso Serliv para uma landing page responsiva de divulgação de cursos, e-books e conteúdos sobre programação.

Este projeto foi desenvolvido usando **apenas HTML, CSS e JavaScript puro**, sem frameworks, bibliotecas de interface ou processo de build. A proposta da página é apresentar a marca fictícia **Dev Ninja** em uma experiência visual voltada para cursos, e-books, depoimentos e conteúdos relacionados ao universo da programação.

  

## Sobre o projeto
  

O **Dev Ninja** é uma landing page estática com navegação por seções, visual responsivo e interações simples em JavaScript. O projeto foi pensado para reunir, em uma única página, áreas de apresentação institucional, vitrine de produtos e chamadas para ação.

  

## Demonstração


**Demo online:** [Clique aqui para ver o projeto rodando](https://modestossm.github.io/Projeto-Dev-Ninja/)

  


## Funcionalidades

  

- Navegação por âncoras entre as principais seções da página

- Hero section com chamada principal e botão de destaque

- Vitrine de cursos com cards e CTAs

- Seção de depoimentos com exibição horizontal

- Área de e-books com descrições e botões de ação

- Bloco de novidades com destaque para canais como WhatsApp e Telegram

- Carrossel de livros recomendados com setas e indicadores

- Rodapé com links para redes sociais

  

## Layout e responsividade

  

O layout foi construído para funcionar bem em diferentes tamanhos de tela, com adaptação entre mobile e desktop por meio de **media queries**. O projeto também usa variações visuais e interações leves, como carrossel, efeitos de hover, organização por grid e ajustes de comportamento quando o JavaScript está habilitado.
